# Pumped Brand Icon & Favicon Synchronization

## Architecture Overview
Pumped uses a light-theme `#FFFFFF` surface with an `#059669` (`emerald-600`) rounded squircle brand badge and crisp `#FFFFFF` `-45°` diagonal dumbbell emblem matching `src/components/layout/TopHeader.tsx`.

Icon outputs are kept synchronized across:
1. `src/app/icon.svg` — scalable vector App Router icon served at `/icon.svg`.
2. `src/app/favicon.ico` — multi-resolution (`16×16`, `32×32`, `48×48`) PNG-packed ICO generated by `scripts/generate-icons.mjs`. Do **not** also place `public/favicon.ico`, because Next.js 15 App Router errors on conflicting `public/favicon.ico` + `src/app/favicon.ico` routes.
3. `src/app/apple-icon.png` and `public/icons/apple-touch-icon.png` — `180×180` full-bleed `#059669` PNG (no transparent corners for iOS home screen).
4. `src/app/layout.tsx` — omit `metadata.icons` when using Next.js 15 file-based icon conventions (`src/app/favicon.ico`, `src/app/icon.svg`, `src/app/apple-icon.png`), because defining `metadata.icons` causes Next.js `resolve-metadata.js` to suppress automatic `<head>` injection of `leafSegmentStaticIcons` (`icon.svg` and `apple-icon.png`).
5. `public/icons/icon-192.png` and `public/icons/icon-512.png` — rounded squircle PNGs with transparent outer corners (referenced by `src/app/manifest.ts`).
6. `public/icons/icon-maskable-512.png` — `512×512` full-bleed `#059669` PNG with safe-zone scaling (`0.78`) for Android adaptive masks.
7. `public/sw.js` — caches `/icons/*` with `cacheFirst`; always bump `SHELL_CACHE`, `STATIC_CACHE`, and `MEDIA_CACHE` version numbers after updating icons so installed PWAs evict stale cached icons.

## Procedure
1. Edit the vector geometry in `src/app/icon.svg` and the matching SDF constants (`EMERALD_600`, `WHITE`, `sampleIconPixel`) in `scripts/generate-icons.mjs`.
2. Run the generator from the project root:
   ```powershell
   node scripts/generate-icons.mjs
   ```
3. Visually inspect `public/icons/icon-192.png`, `public/icons/icon-maskable-512.png`, and `public/icons/apple-touch-icon.png` to verify crisp anti-aliased edges and zero corner clipping.
4. Bump the cache version suffix in `public/sw.js` (`pumped-shell-v*`, `pumped-static-v*`, `pumped-media-v*`).
5. Run the quality gate and production build:
   ```cmd
   cmd /c "cd /d C:\Users\pccoo\.gemini\antigravity\scratch\Pumped && npm run typecheck && npm run lint && npm run test && npm run build"
   ```
6. Start `npm.cmd run dev` (never concurrently with `next build`), verify HTTP `200` and `Content-Type` on `/favicon.ico`, `/icon.svg`, `/apple-icon.png`, `/icons/icon-192.png`, `/icons/icon-512.png`, `/icons/apple-touch-icon.png`, and `/manifest.webmanifest`, and inspect rendered `<head>` icon `<link>` tags in Chrome DevTools MCP (`0` console errors, `0` failed icon requests).
